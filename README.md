# laspv2

A Python project exploring Windows LAPS, cryptographic operations and the protocols involved in retrieving and processing protected directory information.

The project focuses on implementing lower-level functionality rather than relying entirely on existing high-level libraries to avoid antiviruses.

### Features

- AES-GCM encryption and decryption.
- SHA-256, SHA-512 and HMAC operations.
- ConcatKDF key derivation.
- GKDI protocol implementation.
- Custom socket-based DCE/RPC communication.
- RPC Endpoint Mapper functionality.
- NTLM authentication handling.
- Binary structure parsing and processing.

### Technical Overview

The project explores the relationship between Windows directory services, authentication, network protocols and cryptography.

It involves working with binary data, cryptographic primitives, network communication and the implementation of protocol structures in Python.

### Technologies

- Python
- Cryptography
- DCE/RPC
- NTLM
- Windows LAPS
- GKDI
